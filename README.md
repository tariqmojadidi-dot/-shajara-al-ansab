# شجره الانساب

## د کتاب په اړه

**شجره الانساب** د مجددي کورنۍ د نسب او شجرې په اړه یو تاریخي او نسبي اثر دی.

په دې کتاب کې د کورنۍ د نسب سلسلې، د کورنۍ د اولادونو او اړوندو تاریخي معلوماتو د ثبت او ساتنې هڅه شوې ده.

## د کتاب موضوعات

- د مجددي کورنۍ شجره او نسب

- د کورنۍ د نسلونو او اولادونو معلومات

- د شاه ظهورالله د اولادې سلسله

- تاریخي او نسبي معلومات

- د کورنۍ د تاریخي میراث ساتنه
